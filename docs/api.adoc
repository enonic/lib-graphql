= API Reference
:toc: right

This reference covers the public server-side JavaScript modules shipped by GraphQL Library.

== `/lib/graphql`

Import the main module with:

[source,js]
----
const graphQlLib = require('/lib/graphql');
----

=== Scalar constants

The module exports scalar type objects that can be assigned directly to a field or argument's `type` property.

[%header,cols="1,2"]
[frame="none"]
[grid="none"]
|===
| Name | Description

| `GraphQLInt`
| Signed 32-bit integer.

| `GraphQLFloat`
| Double-precision floating-point value.

| `GraphQLString`
| UTF-8 character sequence.

| `GraphQLBoolean`
| `true` or `false`.

| `GraphQLID`
| Identifier serialized as a string.

| `Json`
| Arbitrary JSON-compatible value.

| `Date`
| ISO-8601 calendar date.

| `Time`
| ISO-8601 time with an offset.

| `DateTime`
| ISO-8601 date and time with an offset.

| `LocalDateTime`
| ISO-8601 date and time without a time-zone offset.

| `LocalTime`
| ISO-8601 time without a time-zone offset.
|===

=== Functions

==== `newSchemaGenerator()`

Creates an independent <<schema-generator,SchemaGenerator>>.
Use the same generator for the related types and schema because it also collects resolver registrations.

[.lead]
Returns

<<schema-generator,`SchemaGenerator`>> : Functions for constructing GraphQL types and a schema.

==== `list(type)`

Wraps a type as a GraphQL list.
The list and its items remain nullable unless separately wrapped with `nonNull()`.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `type` | GraphQL type | Type of each list item.
|===

[.lead]
Returns

*GraphQL list type*

==== `nonNull(type)`

Wraps a type as non-null.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `type` | GraphQL type | Type that must not resolve to `null`.
|===

[.lead]
Returns

*GraphQL non-null type*

==== `reference(typeName)`

Creates a type reference by name.
References allow self-referencing or mutually dependent types to be declared before the referenced concrete type exists.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `typeName` | string | Exact GraphQL name of the referenced type.
|===

[.lead]
Returns

*GraphQL type reference*

==== `execute(schema, query, variables, context)`

Executes a GraphQL operation against a schema.
The arguments are positional.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description

| `schema`
| GraphQL schema
| Schema created with `SchemaGenerator.createSchema()`.

| `query`
| string
| GraphQL query, mutation, or subscription document.

| `variables`
| object
| *Optional.* Values for variables declared by the operation.

| `context`
| any
| *Optional.* Application-specific value exposed to resolvers as `env.context`.
|===

[.lead]
Returns

<<execution-result,`ExecutionResult`>> : Query and mutation results contain `data` and, when applicable, `errors`.
For a subscription, `data` is a publisher whose `subscribe()` method accepts a subscriber from `/lib/graphql-rx`.

[#schema-generator]
=== SchemaGenerator

`newSchemaGenerator()` returns the functions in this section.
Except for `createPageInfoObjectType()`, each type-creation call creates a new named GraphQL type.

==== `createSchema()`

Takes one `params` object:

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description

| `query`
| GraphQL object type
| Root query type. Every schema requires one.

| `mutation`
| GraphQL object type
| *Optional.* Root mutation type.

| `subscription`
| GraphQL object type
| *Optional.* Root subscription type.

| `dictionary`
| GraphQL object type[]
| *Optional.* Additional concrete types that are not otherwise reachable when the schema is assembled, including types addressed only through `reference()`.
|===

[.lead]
Returns

*GraphQL schema*

==== `createObjectType()`

Takes one `params` object:

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description

| `name`
| string
| Unique GraphQL type name.

| `fields`
| object
| Map of field names to <<output-field,OutputField>> definitions.

| `interfaces`
| GraphQL interface type[]
| *Optional.* Interfaces implemented by the object. Entries may be concrete interface types or type references.

| `description`
| string
| *Optional.* Description exposed through GraphQL introspection.
|===

[.lead]
Returns

*GraphQL object type*

==== `createPageInfoObjectType()`

Creates the cached page-info object type used by `/lib/graphql-connection`.
The first invocation on a schema generator creates the type; later invocations return that same type.
Application code normally uses `createConnectionType()` instead of calling this directly.

Its `params` properties and return value are the same as `createObjectType()`.

== `/lib/graphql-connection`

This optional module creates Relay-style connection types and opaque cursors.

[source,js]
----
const connectionLib = require('/lib/graphql-connection');
----

=== Functions

==== `createConnectionType(schemaGenerator, type)`

Creates a connection object for a GraphQL object type.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description

| `schemaGenerator`
| <<schema-generator,SchemaGenerator>>
| Generator used to create the schema's related types.

| `type`
| GraphQL object type
| Type returned in each connection edge.
|===

The resolver for a field of the returned connection type must return:

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `total` | number | Total number of available items.
| `start` | number | Zero-based index of the first item in `hits`.
| `hits` | object[] | Items in the current page.
|===

[.lead]
Returns

A GraphQL object type named `<TypeName>Connection` with these fields:

`totalCount`:: Total number of available items.
`edges`:: List containing each `node` and its encoded `cursor`.
`pageInfo`:: `startCursor`, `endCursor`, and `hasNext` for the current page.

==== `encodeCursor(value)`

Converts `value` to a string and returns its Base64 encoding.
The encoding is opaque to GraphQL clients, but it is not encryption and must not contain secrets.

==== `decodeCursor(value)`

Decodes a Base64 cursor and returns its string value.

== `/lib/graphql-rx`

This optional module provides the publisher and subscriber objects used by GraphQL subscriptions.

[source,js]
----
const graphQlRxLib = require('/lib/graphql-rx');
----

=== Functions

==== `createPublishProcessor()`

Creates a <<publish-processor,PublishProcessor>> that can be returned by a subscription field resolver.

==== `createSubscriber()`

Takes one `params` object:

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `onNext` | function | *Optional.* Called with each mapped <<execution-result,ExecutionResult>> produced by a subscription.
|===

[.lead]
Returns

<<subscription-subscriber,`SubscriptionSubscriber`>>

[#publish-processor]
=== PublishProcessor

A reactive event source returned by `createPublishProcessor()`.

`onNext(value)`:: Publishes a value to active subscribers.
`onError(error)`:: Terminates the stream with an error.
`onComplete()`:: Completes the stream.
`filter(predicate)`:: Returns a publisher that forwards only values for which `predicate(value)` is truthy.
`subscribe(subscriber)`:: Subscribes a compatible reactive-streams subscriber.

[#subscription-subscriber]
=== SubscriptionSubscriber

A subscriber returned by `createSubscriber()`.

`cancelSubscription()`:: Cancels its active subscription. Calling it before subscription or more than once has no effect.

[#type-definitions]
== Type definitions

[#output-field]
=== OutputField

Defines a field on an object type.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description

| `type`
| GraphQL output type
| Field result type.

| `args`
| object
| *Optional.* Map of argument names to GraphQL input types.

| `resolve`
| function or value
| *Optional.* Resolver invoked with a <<resolver-environment,ResolverEnvironment>>, or a fixed value. When omitted, GraphQL reads a property with the field's name from `env.source`.
|===

[#interface-field]
=== InterfaceField

Defines a field on an interface.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `type` | GraphQL output type | Field result type.
| `args` | object | *Optional.* Map of argument names to GraphQL input types.
|===

[#input-field]
=== InputField

Defines a field on an input object.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `type` | GraphQL input type | Input field type.
|===

[#resolver-environment]
=== ResolverEnvironment

The object passed to an output-field resolver.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `source` | any | Value returned by the parent field.
| `args` | object | Arguments supplied for the current field.
| `context` | any | Context passed to `execute()`.
|===

[#execution-result]
=== ExecutionResult

The mapped result returned by `execute()` and delivered to subscription callbacks.

[%header,cols="1,1,4a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description

| `data`
| object or publisher
| Resolved operation data. A subscription returns a publisher instead of an object.

| `errors`
| object[]
| *Optional.* Validation or data-fetching errors. Each error includes `errorType` and `message`, and may include `locations`, `validationErrorType`, or `exception`.
|===
