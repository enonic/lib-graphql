= /lib/graphql-connection
:toc: right

This optional module creates Relay-style connection types and the opaque cursors they expose.

== Functions

[#create-connection-type]
=== createConnectionType

Creates a connection object type for a GraphQL object type.

[.lead]
Parameters

`createConnectionType()` takes two positional arguments:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `schemaGenerator` | <<graphql#schema-generator,SchemaGenerator>> | Generator used to create the schema's related types.
| `type` | GraphQL object type | Type returned in each connection edge.
|===

[.lead]
Returns

A GraphQL object type named `<TypeName>Connection` with these fields:

`totalCount`:: Total number of available items.
`edges`:: List containing each `node` and its encoded `cursor`.
`pageInfo`:: `startCursor`, `endCursor`, and `hasNext` for the current page.

The resolver for a field of this type must return a <<connection-source,ConnectionSource>>.

[.lead]
Example

The connection type is created from an existing object type, then used as the type of a field that returns a page of results.
The resolver maps the query result onto the three <<connection-source,ConnectionSource>> properties.

.Creates `PersonConnection` and pages through results with it:
[source,js]
----
const graphQlLib = require('/lib/graphql');
const connectionLib = require('/lib/graphql-connection');
const peopleLib = require('/lib/people');

const personConnectionType = connectionLib.createConnectionType(schemaGenerator, personType);

const rootQueryType = schemaGenerator.createObjectType({
    name: 'Query',
    fields: {
        people: {
            type: personConnectionType,
            args: {
                start: graphQlLib.GraphQLInt,
                count: graphQlLib.GraphQLInt
            },
            resolve: (env) => {
                const result = peopleLib.find({
                    start: env.args.start,
                    count: env.args.count
                });

                return {
                    total: result.total,
                    start: env.args.start,
                    hits: result.hits
                };
            }
        }
    }
});
----

=== encodeCursor

Converts `value` to a string and returns its Base64 encoding.
The encoding is opaque to GraphQL clients, but it is not encryption and must not contain secrets.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `value` | any | Value to encode. Converted with `String()` before encoding.
|===

[.lead]
Returns

`string` — Base64-encoded cursor.

[.lead]
Example

Types created by `createConnectionType()` encode their own cursors.
Call `encodeCursor()` directly only when building a connection-shaped type by hand.

.Encodes an offset as a cursor:
[source,js]
----
const cursor = connectionLib.encodeCursor(20);
----

.Return value:
[source,js]
----
const expected = 'MjA=';
----

=== decodeCursor

Decodes a Base64 cursor.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `value` | any | Cursor to decode. Converted with `String()` before decoding.
|===

[.lead]
Returns

`string` — decoded cursor value.

[.lead]
Example

The decoded value is always a string, so parse it before using it as a number.

.Turns a client-supplied cursor back into a start offset:
[source,js]
----
const value = connectionLib.decodeCursor('MjA=');

const start = parseInt(value, 10);
----

.Return value:
[source,js]
----
const expected = '20';
----

== Type Definitions

[#connection-source]
=== ConnectionSource

The value a resolver must return for a field whose type was created by <<create-connection-type,createConnectionType()>>.

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `total` | number | Total number of available items.
| `start` | number | Zero-based index of the first item in `hits`.
| `hits` | object[] | Items in the current page.
|===
