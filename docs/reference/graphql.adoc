= /lib/graphql
:toc: right

The main module defines GraphQL types, assembles them into a schema, and executes operations against that schema.

== Usage

[source,js]
----
const graphQlLib = require('/lib/graphql');
----

== Functions

=== newSchemaGenerator

Creates an independent <<schema-generator,SchemaGenerator>>.
Use the same generator for the related types and the schema, because it also collects resolver registrations.

[.lead]
Returns

<<schema-generator,`SchemaGenerator`>> — functions for constructing GraphQL types and a schema.

=== list

Wraps a type as a GraphQL list.
The list and its items remain nullable unless separately wrapped with `nonNull()`.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `type` | GraphQL type | Type of each list item.
|===

[.lead]
Returns

GraphQL list type.

=== nonNull

Wraps a type as non-null.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `type` | GraphQL type | Type that must not resolve to `null`.
|===

[.lead]
Returns

GraphQL non-null type.

=== reference

Creates a type reference by name.
References allow self-referencing or mutually dependent types to be declared before the referenced concrete type exists.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `typeKey` | string | Exact GraphQL name of the referenced type.
|===

[.lead]
Returns

GraphQL type reference.

=== execute

Executes a GraphQL operation against a schema.
The arguments are positional.

[.lead]
Parameters

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `schema` | GraphQL schema | Schema created with `SchemaGenerator.createSchema()`.
| `query` | string | GraphQL query, mutation, or subscription document.
| `variables` | object | *Optional.* Values for variables declared by the operation.
| `context` | any | *Optional.* Application-specific value exposed to resolvers as `env.context`.
|===

[.lead]
Returns

<<execution-result,`ExecutionResult`>> — query and mutation results contain `data` and, when applicable, `errors`.
For a subscription, `data` is a publisher whose `subscribe()` method accepts a subscriber from <<graphql-rx#,`/lib/graphql-rx`>>.

[.lead]
Example

[source,js]
----
const result = graphQlLib.execute(
    schema,
    'query SayHello($name: String!) { greeting(name: $name) { message } }',
    {name: 'Ada'},
    {requestId: 'example-request'}
);
----

== Classes

[#schema-generator]
=== SchemaGenerator

Type and schema factory returned by `newSchemaGenerator()`.
Except for `createPageInfoObjectType()`, each type-creation method creates a new named GraphQL type.

==== createSchema

Assembles the schema from its root types.
Takes a single `params` object with these properties:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `query` | GraphQL object type | Root query type. Every schema requires one.
| `mutation` | GraphQL object type | *Optional.* Root mutation type.
| `subscription` | GraphQL object type | *Optional.* Root subscription type.
| `dictionary` | GraphQL object type[] | *Optional.* Additional concrete types that are not otherwise reachable when the schema is assembled, including types addressed only through `reference()`.
|===

[.lead]
Returns

GraphQL schema.

==== createObjectType

Creates an object type.
Takes a single `params` object with these properties:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `name` | string | Unique GraphQL type name.
| `fields` | object | Map of field names to <<output-field,OutputField>> definitions.
| `interfaces` | GraphQL interface type[] | *Optional.* Interfaces implemented by the object. Entries may be concrete interface types or type references.
| `description` | string | *Optional.* Description exposed through GraphQL introspection.
|===

[.lead]
Returns

GraphQL object type.

==== createPageInfoObjectType

Creates the cached page-info object type used by <<graphql-connection#,`/lib/graphql-connection`>>.
The first invocation on a schema generator creates the type; later invocations return that same type.
Application code normally uses `createConnectionType()` instead of calling this directly.

Its `params` properties and return value are the same as `createObjectType()`.

==== createInputObjectType

Creates an input object type for use in field arguments.
Takes a single `params` object with these properties:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `name` | string | Unique GraphQL input type name.
| `fields` | object | Map of field names to <<input-field,InputField>> definitions.
| `description` | string | *Optional.* Description exposed through GraphQL introspection.
|===

[.lead]
Returns

GraphQL input object type.

==== createInterfaceType

Creates an interface type.
Takes a single `params` object with these properties:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `name` | string | Unique GraphQL interface name.
| `fields` | object | Map of field names to <<interface-field,InterfaceField>> definitions.
| `typeResolver` | function | Receives the source value and returns the concrete GraphQL object type for that value.
| `description` | string | *Optional.* Description exposed through GraphQL introspection.
|===

[.lead]
Returns

GraphQL interface type.

==== createUnionType

Creates a union type.
Takes a single `params` object with these properties:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `name` | string | Unique GraphQL union name.
| `types` | GraphQL object type[] | Non-empty array of possible concrete types. Entries may be object types or type references.
| `typeResolver` | function | Receives the source value and returns its concrete GraphQL object type.
| `description` | string | *Optional.* Description exposed through GraphQL introspection.
|===

[.lead]
Returns

GraphQL union type.

==== createEnumType

Creates an enum type.
Takes a single `params` object with these properties:

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `name` | string | Unique GraphQL enum name.
| `values` | string[] or object | Enum names as an array, or an object mapping GraphQL enum names to their runtime values.
| `description` | string | *Optional.* Description exposed through GraphQL introspection.
|===

[.lead]
Returns

GraphQL enum type.

== Type definitions

[#output-field]
=== OutputField

Defines a field on an object type.

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `type` | GraphQL output type | Field result type.
| `args` | object | *Optional.* Map of argument names to GraphQL input types.
| `resolve` | function or value | *Optional.* Resolver invoked with a <<resolver-environment,ResolverEnvironment>>, or a fixed value. When omitted, GraphQL reads a property with the field's name from `env.source`.
|===

[#interface-field]
=== InterfaceField

Defines a field on an interface.

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `type` | GraphQL output type | Field result type.
| `args` | object | *Optional.* Map of argument names to GraphQL input types.
|===

[#input-field]
=== InputField

Defines a field on an input object.

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `type` | GraphQL input type | Input field type.
|===

[#resolver-environment]
=== ResolverEnvironment

The object passed to an output-field resolver.

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `source` | any | Value returned by the parent field.
| `args` | object | Arguments supplied for the current field.
| `context` | any | Context passed to `execute()`.
|===

[#execution-result]
=== ExecutionResult

The mapped result returned by `execute()` and delivered to subscription callbacks.

[%header,cols="1%,1%,98%a"]
[frame="none"]
[grid="none"]
|===
| Name | Type | Description
| `data` | object or publisher | Resolved operation data. A subscription returns a publisher instead of an object.
| `errors` | object[] | *Optional.* Validation or data-fetching errors. Each error includes `errorType` and `message`, and may include `locations`, `validationErrorType`, or `exception`.
|===

== Constants

The module exports scalar type objects that can be assigned directly to a field or argument's `type` property.

[%header,cols="1,3"]
|===
| Export | Description

| `GraphQLInt`
| Signed 32-bit integer.

| `GraphQLFloat`
| Double-precision floating-point value.

| `GraphQLString`
| UTF-8 character sequence.

| `GraphQLBoolean`
| `true` or `false`.

| `GraphQLID`
| Identifier serialized as a string.

| `Json`
| Arbitrary JSON-compatible value.

| `Date`
| ISO-8601 calendar date.

| `Time`
| ISO-8601 time with an offset.

| `DateTime`
| ISO-8601 date and time with an offset.

| `LocalDateTime`
| ISO-8601 date and time without a time-zone offset.

| `LocalTime`
| ISO-8601 time without a time-zone offset.
|===
